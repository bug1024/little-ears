# Little Ears 0.4 · 音响设备材质系统

目标是提高日常使用的信息密度，保留音乐库、播放列表、正在播放、统计和设置的结构。视觉中心由真实音频频谱承担，弱化品牌插画，不引入歌词或新的内容服务。

采用系统字体：页面标题 16 pt、当前曲目 26 pt、表格正文 12 pt、次级信息 10–11 pt。时间和序号使用等宽数字，不为装饰引入英文字母眉题、超大口号或新字体。

- 导航侧栏默认 196 pt，使用原生分隔线拖动到 360 pt；900 pt 窗口上限为 280 pt，确保内容区至少约 620 pt。目录和列表名称悬停显示完整文本。导航行 31 pt，目录行 27 pt；图标与标题对齐，强调色用于少量状态。
- 页面头 48 pt，操作栏 42 pt。音乐库和播放列表共用 32 pt 表格行，名称／目录／时长／格式保持统一列宽。
- 队列行 52 pt，行间距 0；显示固定序号、标题、来源和时长。普通项仅用细分隔线，当前项用浅底色、2 pt 竖条与播放／暂停图标，不加描边或阴影。播放状态使用强调色，暂停使用中性灰；当前项在暂停时仍可辨识。
- 底部播放器 68 pt，曲目信息、切歌控制、进度和音量在同一行组织。
- 正在播放将真实频谱、进度和曲目信息整合进一块 16 pt 圆角内嵌显示屏；不再重复列出接下来两首。格式标签可点开时长、文件大小和队列位置。播放页的进度放在显示屏，其余页面放在底栏。
- 统计为一组分隔指标、紧凑图表和排名表格，数值仍全部来自真实记录。
- 设置使用统一材质分组，保留原生分段控件和开关。强调色为可点击色块，提供明确选中标记和辅助功能标签。新建／重命名列表弹窗共享按钮和内嵌输入框样式。

## 全局材质与控件

- 主背景、浮起表面和内嵌显示屏共享 Palette / MaterialSurface；侧栏、工具栏和底栏采用克制的炭灰／银灰明暗渐变。
- 普通工具栏与弹窗按钮采用系统 bordered / borderedProminent 样式；底部圆形切歌、珍珠白主播放按钮保留产品材质。定制播放控件按下缩放到 0.96，系统减少动态效果时关闭缩放。
- 列表继续 32 pt 行高，使用内嵌面板、弱交替背景和细分隔；导航选中项采用统一浮起材质。
- 进度和音量保留 NSSlider 的鼠标、键盘和辅助功能机制，仅覆盖轨道与滑块绘制。4 pt 轨道显示真实数值，12 pt 珍珠白滑块；外层控件高 18 pt。进度仅在拖动结束后 seek，键盘变更立即 seek。
- 浅色采用雾白与银灰层次；频谱蓝色保持对比，光晕关闭，倒影显著减弱。

## 频谱

播放引擎音量调节前输出 PCM → 非阻塞环形缓冲 → 后台 Hann 窗 / FFT → 对数频率分组 / dB 映射 / 平滑与峰值衰减 → 独立显示对象 → Canvas。

暂停冻结最后一帧；首次恢复到暂停状态、或暂停时拖动进度，从当前位置的文件 PCM 读取一帧频谱快照，不启动播放或记录统计；切歌和拖动清空旧数据；离开页面、隐藏或最小化窗口停止分析更新。支持设置关闭。没有音频时不会产生随机动画。内部仍按 −80 至 0 dB 和对数频段映射，默认画面不显示分析坐标／网格。64 根渐变柱与峰值帽取自真实 FFT；轻光晕和短倒影仅是相同数据的绘制层，不产生额外波形或随机动画。

## 0.4.2 有边界的精修

侧栏单独通过实际 NSSplitView 的分隔线约束验证：1140 pt 窗口请求 100、340、500 pt 分别得到 196、340、360 pt；缩到 900 pt 后请求 500 pt 得到 280 pt。通过系统 autosaveName 保存分隔线位置；预览关闭持久化，不改写实际应用侧栏偏好。未添加自定义鼠标捕获层。导航结构、色系、底栏高度及统计页面没有改动。

追加深浅播放状态和侧栏最小／宽／最大／小窗口快照。分隔线约束通过离屏 AppKit 实际布局验证；物理鼠标拖动仍需结合日常使用验收。

本轮共生成 22 张快照。播放状态快照在内存库中以音量 0 播放，仅检查状态色与控件关系；实时频谱因真实静音为零。暂停快照使用真实歌曲对应位置 PCM 显示非零频谱，真实播放 tap 另由测试验证。最终实机操作因 Mac 锁屏未完成，未声称物理拖动已验收。

## 0.4.4 播放列表本身的管理与空格

数据库 v4 增加 playlists.position，并按原创建顺序初始化旧列表。拖动通过单一事务只更新列表位置，不重写歌曲、列表名称或历史；新列表追加末尾，重命名保留排序。排序、删除和新建继续保留当前队列的独立性。

主窗口安装局部键盘事件监听，空格切换播放／暂停；输入框、文本编辑器、按钮、菜单以及弹窗保留自身行为。监听只处理对应的前台主窗口，不影响设置、其他应用或后台窗口；按键重复不反复切换。监听随视图移除而注销。

## 0.4.5 方向键

主窗口局部事件监听扩展为 PlaybackKeyboardShortcuts：↑／↓ 每次 ±5% 音量并限制为 0～100%，支持长按重复；←／→ 上一首／下一首，重复按键不会连续切歌。左键使用独立 previousTrack，当前曲目已播放超过 3 秒时也直接换曲；第一首在队列循环模式下回到末首，其他模式下回到开头。原有按钮和 ⌘← 行为保留。

普通方向键在歌曲列表或按钮获得焦点时也控制播放器。输入框、下拉选择器、滑块及其子视图保留原生操作；修饰键、菜单、弹窗、其他窗口和后台应用不被捕获。Shift＋方向键仍用于列表扩选。音量变更同步到播放器并保存。

27 项测试通过（含 jay 实库），新增方向键映射／列表焦点／子控件避让与重复策略检查，以及真实音频的直接上一首／下一首、音量上下限和重启恢复测试。Release 和 Xcode 构建通过。

实机验证主窗口 ↑ 将音量从 69.49% 调到 74.49%，↓ 回到原值；选中歌曲后 ↑ 仍调整音量而不移动选择。后续应用状态发生变化，停止继续操作；左右切歌及控件避让由独立真实音频／键盘策略测试验证，未声称全部物理按键组合均已实机验收。

## 0.4.6 键盘范围、频谱连续性与原生控件

裸方向键只在正在播放页、没有输入框／列表／滑块焦点时控制播放器；音乐库和播放列表交回系统导航。没有增加 ⌘↑／⌘↓。空格与已有 ⌘P、⌘←／⌘→ 保持可用。

实时 tap 移到 player node，输出音量移到下游 mixer，因此实时频谱和暂停快照均基于音量调节前的实际 PCM。同一首歌暂停／恢复只重启采集，不清空 FFT 平滑历史；切歌、seek 和采样率变化仍清空历史，防止旧音频残留。epoch／revision 标记在主线程应用前再次核对，拒绝过期音频帧，同时允许新歌曲的清空帧在激活后正确应用。暂停位置快照只读取一段 PCM，反复计算该段以稳定初始平滑，不再读取后续约一秒内容。

普通工具栏、目录添加／设置按钮及列表名称弹窗回到系统按钮样式；播放控制圆形按钮、频谱和现有层级保留。没有额外加光晕、倒影或跨歌曲混合动画，也没有改 FFT 的 dB 映射和 attack / release 参数。

31 项测试通过，包括 jay 实库、播放页范围／列表焦点避让、静音与低音量时真实 tap 一致性、暂停／恢复能量保持、精确位置快照、低电平 PCM／静音衰减，以及过期帧与清空帧的代际检查。Release、Xcode 和签名检查通过。

真实音乐动态预览有 40 个采样帧，覆盖开始、暂停、恢复、跳转和切歌；暂停段 FFT 数值变化为 0。预览输出静音、在内存数据库运行，另记录逐帧 FFT JSON；GIF 是低帧率采样，不能作为实际帧率或全部抖动场景的验收证据。低电平响应由 PCM 测试覆盖，尚未拿实际安静故事素材进行专项主观体验。深浅及紧凑布局预览同步更新。

实机检查音乐库下键从第一首移到第二首且音量不变；正在播放页 ↑／↓ 每次增减 5%，验证后恢复原音量。保留「怎么了」原暂停位置 135.36 秒，未修改实际列表内容。
