# Little Ears 0.3 · 原生视觉系统

目标是提高日常使用的信息密度，保留音乐库、播放列表、正在播放、统计和设置的结构。视觉中心由真实音频频谱承担，弱化品牌插画，不引入歌词或新的内容服务。

## 视觉基准

| 角色 | 深色 | 浅色 |
|---|---|---|
| 主背景 | #1B1D21 | #F4F5F7 |
| 侧栏 | #202226 | #ECEEF1 |
| 表面 | #23252A | #FFFFFF |
| 提升层 | #2B2E34 | #E8EBEF |

| 次级文字 | #9A9FA8 | #737A85 |
| 冰川蓝 | #80C8F2 | #347DB2 |

采用系统字体：页面标题 16 pt、当前曲目 22 pt、表格正文 12 pt、次级信息 10–11 pt。时间和序号使用等宽数字，不为装饰引入英文字母眉题、超大口号或新字体。

- 导航侧栏 196 pt，导航行 31 pt，目录行 27 pt；图标与标题对齐，强调色用于少量状态。
- 页面头 48 pt，操作栏 42 pt。音乐库和播放列表共用 32 pt 表格行，名称／目录／时长／格式保持统一列宽。
- 队列行 43 pt，显示标题、来源和时长。当前项使用细强调线和低透明度背景，减少逐条卡片描边。
- 底部播放器 68 pt，曲目信息、切歌控制、进度和音量在同一行组织。
- 正在播放以频谱、曲目来源、时长、文件大小、队列位置和接下来两首音频构成内容重心。
- 统计为一组分隔指标、紧凑图表和排名表格，数值仍全部来自真实记录。
- 设置沿用原生 Form 和分段控件，强调色为可点击色块，提供明确选中标记和辅助功能标签。

## 频谱

播放引擎输出 PCM → 非阻塞环形缓冲 → 后台 Hann 窗 / FFT → 对数频率分组 / dB 映射 / 平滑与峰值衰减 → 独立显示对象 → Canvas。

暂停冻结最后一帧；首次恢复到暂停状态、或暂停时拖动进度，从当前位置的文件 PCM 读取一帧频谱快照，不启动播放或记录统计；切歌和拖动清空旧数据；离开页面、隐藏或最小化窗口停止分析更新。支持设置关闭。没有音频时不会产生随机动画。频率标签按对数坐标放置，纵轴对应 −80 至 0 dB 的显示映射。

## 验证

- 19 项测试通过，保留原有播放、FLAC、队列／列表独立性、统计和数据库迁移验证。
- 新增 FFT 与暂停快照测试验证 44.1/48 kHz 下的音调位置、静音和衰减、右声道 PCM，以及实时播放 tap 的频率结果与停用状态。
- 离屏检查覆盖 1140×730 深浅页面、设置和 900×600 紧凑窗口；修正表头对齐和设置内容裁切。
- 预览使用 jay 目录的实际歌曲，测试列表只存在于独立内存数据库；截图频谱由真实文件 PCM 计算，未写入用户的音乐库或历史数据。
- 已实机检查主窗口、正在播放页面、恢复的用户队列和设置窗口；尚未逐项完成拖拽、键盘与媒体键实机验收；未声称完成专项性能或长期稳定性验证。
