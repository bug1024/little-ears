# M1 实施约定

本次交付可运行的原生 macOS 14+ 首版，优先验证真实音频导入与日常播放体验。采用 SwiftUI、AVAudioEngine / AVAudioPlayerNode、SQLite / GRDB。开发依赖需首次联网下载，应用运行完全离线。

- 单主窗口，关闭窗口保持播放；Dock 点击重新打开。退出保存检查点。睡眠/输出设备变化暂停，不自动恢复发声。
- 播放队列为独立 ID 的快照；双击按当前筛选与排序结果创建队列，从所选项开始。目录默认直接子文件，可选择包含子目录。自然排序。
- 上一首：播放超过 3 秒回到开头，否则上一项；首项回到开头。下一首切换，即使在单曲循环中。顺序模式最后一项停止；不可用项自动跳过，一轮全部失效则停止。
- 重启恢复队列、曲目和位置，但不自动播放。
- 完整播放：自然结束且内容覆盖率 ≥90%；重复听同一区间不增加覆盖率。拖动至末尾不能获得完成次数。暂停/继续沿用会话；手动切歌、退出结束会话，重启新建会话。循环每一轮新建会话。
- 时长：单调时钟，只有真实播放进度推进时记账；不累计暂停、拖动跳跃、睡眠。每 5 秒检查点，崩溃最多丢失约 5 秒。按记录发生时本地自然日归档，变更时区不重写历史；周一为周起点。完成次数按结束当天归属。
- 文件身份使用来源内文件系统标识、创建日期、大小；重命名/同来源内移动可关联，无法确认不自动合并。跨来源/跨磁盘移动暂不自动恢复。相同内容副本独立统计。禁止重复或重叠导入目录。
- 扫描失败保留旧记录；扫描成功后未找到的音频标为不可用。仅引用原音频，不复制、不改写。持久化目录书签。
- M1 格式：MP3、M4A、WAV、AIFF、CAF、FLAC；最终以系统可解码为准，损坏文件保留明确错误。元数据标题优先，空值回退文件名。
- M1 包含真实统计基础和基础统计页、音乐库与目录浏览、队列、主题和强调色。已增量实现播放列表编排；歌词和真实 FFT 频谱待后续完成。
- 播放列表有独立持久化条目 ID，允许重复歌曲。列表按保存的顺序播放，双击重复歌曲时定位到具体条目。拖拽排序自动写入 SQLite；仅在事务成功后更新界面。修改列表不改动当前队列。
- 当前队列可另存为新播放列表，或在明确确认后覆盖指定列表的歌曲与顺序。删除列表只删除引用，不删除原文件、Track 和统计，也不改变当前队列。
- 首版本地开发分发，未开启 App Sandbox；使用安全作用域书签，为后续沙盒分发准备。发布签名、公证、完整文件重关联属于后续稳定性工作。

## 验收

编译与核心规则测试通过；生成可启动 .app；导入本地音频后可播放、暂停、拖动、切歌与循环；重新启动恢复位置且保持暂停；不可用文件不删除历史；空库有明确导入操作。性能测量以真实资源后续确认，不声称已经通过一周稳定性验证。
