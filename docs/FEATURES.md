# 睡眠定时、单曲统计与听力足迹

## 实现

- SleepTimerManager 独立管理运行期状态、截止时间与秒级剩余时间；不写数据库，倒计时不广播到整个 AppModel。暂停、切歌和关窗不重置截止时间，唤醒与窗口恢复时检查到期，退出时取消。
- 当前曲目结束模式在自然完成的已有统计处理之后阻断循环与自动下一首。已暂停的迟到完成回调不会重复结算。定时暂停只保留实际播放时长，不新增完整次数。
- 单曲累计时长从 fragments 汇总，完整次数从 sessions 汇总；最近播放采用有正时长片段的最近会话开始时间，累计天数按片段自然日去重。
- 历史会话按开始时间及 ID 倒序，以游标分批读取（默认 50 条）。区间筛选按片段日期判断；跨日会话显示整次时长，趋势按日拆分。
- 年度时长与 completedDay 完整次数分别聚合再组合，避免一对多连接重复累计。年度数据一次按需读取，指标和悬停不触发查询；现有播放检查点变化可更新当前年份。
- ListeningCalendar 将日期、星期一开始的周位置、闰年、今天和未来日期映射与绘制分离。热力阈值集中定义，配色按主题做不透明混色；未来日期独立禁用样式。
- 日期详情按 Track ID 合并时长和完成次数，按实际时长倒序；文件失效或元数据缺失不丢历史。日详情内复用单曲详情，未新增一级导航。

## 验证

40 项测试通过，包含真实 jay 音乐库回归。新增 9 项测试覆盖可控截止时间、替换与取消、循环模式下曲目结束停止、部分播放、暂停／切歌／窗口恢复、重启不恢复定时、日历与阈值边界、统计分页与跨午夜／跨年聚合、文件失效与列表删除后保留历史。

功能截图来自只读 SQLite 在线备份到内存数据库，不修改真实列表或历史，不注入示例统计。覆盖深浅主题、四种强调色、620×540 详情和 900×600 窗口。系统休眠／唤醒以及真实 15～60 分钟整段定时仍需长期实机验证，可控时钟测试不替代这项验收。

原生窗口实测已验证：睡眠定时弹出菜单及实时倒计时、年度足迹打开当天记录、当天音频进入单曲详情并关闭返回。检查后恢复正在播放页面，保留原有播放和定时状态。Release 打包、Xcode Debug 构建及应用签名校验通过。
