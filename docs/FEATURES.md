# 功能实现说明

## 睡眠定时、单曲统计与听力足迹

### 实现

- SleepTimerManager 独立管理运行期状态、截止时间与秒级剩余时间；不写数据库，倒计时不广播到整个 AppModel。暂停、切歌和关窗不重置截止时间，唤醒与窗口恢复时检查到期，退出时取消。
- 当前曲目结束模式在自然完成的已有统计处理之后阻断循环与自动下一首。已暂停的迟到完成回调不会重复结算。定时暂停只保留实际播放时长，不新增完整次数。
- 单曲累计时长从 fragments 汇总，完整次数从 sessions 汇总；最近播放采用有正时长片段的最近会话开始时间，累计天数按片段自然日去重。
- 历史会话按开始时间及 ID 倒序，以游标分批读取（默认 50 条）。区间筛选按片段日期判断；跨日会话显示整次时长，趋势按日拆分。
- 年度时长与 completedDay 完整次数分别聚合再组合，避免一对多连接重复累计。年度数据一次按需读取，指标和悬停不触发查询；现有播放检查点变化可更新当前年份。
- ListeningCalendar 将日期、星期一开始的周位置、闰年、今天和未来日期映射与绘制分离。热力阈值集中定义，配色按主题做不透明混色；未来日期独立禁用样式。
- 日期详情按 Track ID 合并时长和完成次数，按实际时长倒序；文件失效或元数据缺失不丢历史。日详情内复用单曲详情，未新增一级导航。

### 验证

40 项测试通过，包含真实 jay 音乐库回归。新增 9 项测试覆盖可控截止时间、替换与取消、循环模式下曲目结束停止、部分播放、暂停／切歌／窗口恢复、重启不恢复定时、日历与阈值边界、统计分页与跨午夜／跨年聚合、文件失效与列表删除后保留历史。

功能截图来自只读 SQLite 在线备份到内存数据库，不修改真实列表或历史，不注入示例统计。覆盖深浅主题、四种强调色、620×540 详情和 900×600 窗口。系统休眠／唤醒以及真实 15～60 分钟整段定时仍需长期实机验证，可控时钟测试不替代这项验收。

原生窗口实测已验证：睡眠定时弹出菜单及实时倒计时、年度足迹打开当天记录、当天音频进入单曲详情并关闭返回。检查后恢复正在播放页面，保留原有播放和定时状态。Release 打包、Xcode Debug 构建及应用签名校验通过。


## 本地歌词

### 入口与数据

- `Lyrics.swift` 包含解析、自动匹配及 `LyricsLibrary` 导入状态；`LyricsViews.swift` 包含全文、紧凑歌词和关联管理。播放页右侧使用「队列／歌词」切换，曲目信息旁显示当前句和下一句；展开全文后紧凑歌词收起。沉浸全屏不展示歌词。
- `Database.swift` 的 `v5-local-lyrics` 迁移创建 `lyrics` 表，字段为 `id`、`filename`、`sourcePath`、`text`、可空且唯一的 `trackID`。正文复制到资料库，原始路径用于来源与匹配，不依赖原文件持续存在。曲目删除时解除关联并保留文本；同一曲目只能关联一份导入记录。
- 文件读取、匹配和解析缓存构建在后台进行，正文与关联通过数据库事务保存。歌词阅读视图独立观察播放位置，不将逐帧变化广播到整个页面。应用不扫描内嵌歌词，也没有在线搜索或下载入口。

### 解析与匹配

- 支持 LRC 与 TXT，编码为 UTF-8、带 BOM 的 UTF-16 或 GB18030；单文件上限 2 MB。文件夹导入递归扫描，跳过隐藏项和包内容；空内容、无法解码或无有效文本的文件不写入。
- LRC 支持分钟／小时格式、多时间标签、毫秒偏移与同时间翻译合并；时间排序后随进度高亮，点击行可跳转，关闭跟随可自由阅读。TXT 不解释时间或元数据标签；无有效时间标签的 LRC 回退为纯文本。
- 匹配依次检查同目录同文件名、全库同文件名，再检查文件名别名和元数据标题。规范化忽略大小写、宽度、常见开头编号及分隔符；标题回退还检查现场、伴奏、混音和重制标记，并在文件名含明确歌手前缀时比较前缀。文件名带版本标记时不使用 LRC 标题标签扩大候选。这里不做时长、专辑或简繁转换匹配。
- 只有唯一曲目候选且没有重复歌词候选时才自动关联。同一来源路径和相同正文复用已有记录；改过正文作为新记录导入。默认保留已有关联，已导入的待关联记录也参与冲突检查。
- 文件选择窗口的「覆盖已关联歌词」默认关闭。启用后只对本次导入文件做候选冲突检查，避免旧的未关联版本阻止替换；匹配不明确、文件无效或读取失败时保留原关联。替换会解除旧记录的关联，保留旧正文。导入结果显示新增、替换、保留及待关联数量，另列未导入错误。
- 管理界面可手动关联、替换或解除；手动指定当前音频不依赖自动匹配。用户操作见 [README](../README.md#播放与队列)，外部文件准备见 [脚本说明](../scripts/lyrics/README.md)。

### 验证

```sh
swift test --filter LyricsTests
```

测试覆盖时间标签、偏移、翻译与跳转、纯文本及换行、匹配优先级与版本保护、重复候选、默认保留、覆盖导入、无效文件保护、编码与资料库重新打开后的持久化。脚本的文件检查不能替代应用解析测试或实际播放中的歌词时间轴核对。
