# Little Ears

Little Ears 是一款 macOS 原生本地音频播放器，适合英语熏听、故事播放和日常听音乐。音频保留在原来的文件夹中，应用完全离线运行。

支持 MP3、M4A、WAV、AIFF、CAF 和 FLAC，要求 macOS 14 或更新版本。

## 开始使用

1. 将 `Little Ears.app` 放入「应用程序」，打开应用。
2. 在「音乐库」点击「选择文件夹」或「添加目录」，选择音频所在的文件夹。
3. 双击一首歌曲开始播放，或点击「播放」按当前列表顺序播放。

添加目录只会建立索引，不会复制、移动或修改原始音频。点击左侧目录可浏览其中的歌曲；勾选「子目录」可同时查看下级文件夹中的音频。音乐库支持搜索，以及按名称或时长排序。

拖动侧栏右缘可调整宽度，悬停在较长的目录或列表名称上可查看完整名称。

## 选择多首歌曲

- 单击选中一首歌曲。
- 按住 `⌘` 点击，添加或取消不连续的选择。
- 先选一首，再按住 `Shift` 点击另一首，选中连续范围。
- 点击列表底部的「全选」或「取消选择」，批量调整选择。

音乐库选中歌曲后，点击「加入播放列表」，选择已有列表或新建列表。可以从不同目录分批加入歌曲；点击「播放所选」可只播放选中的歌曲。

## 管理播放列表

播放列表用于保存挑选的歌曲及其播放顺序，同一首歌曲可以加入多次。

- **新建**：点击左侧「播放列表」旁的 `+`，或从音乐库选择歌曲后新建列表。
- **重命名／删除**：右键点击左侧的具体列表名称，或使用列表页右上角的「…」菜单。
- **调整列表顺序**：拖动左侧列表名称，顺序自动保存。
- **调整歌曲顺序**：拖动歌曲左侧的排序手柄，顺序自动保存。
- **移除歌曲**：多选后点击「移除所选」，或在歌曲列表获得焦点时按 `Delete`。
- **播放**：打开列表后点击「播放」，或双击某首歌曲从该处开始。

删除列表或移除歌曲只影响播放列表，原始音频、播放记录和当前播放队列都会保留。

## 播放与队列

「正在播放」显示当前曲目、播放进度、实时音频频谱和播放队列。底部播放器提供暂停、切歌、音量及播放模式控制，支持顺序播放、队列循环和单曲循环。

播放页的进度条位于频谱面板内；其他页面可通过底部进度条调整播放位置。实时频谱随音源内容变化，不受播放音量影响；暂停时保留画面，也可以在设置中关闭。

右侧队列支持双击跳转和拖拽排序。点击「保存队列」可另存为新播放列表，或确认后覆盖已有列表。

播放列表与当前队列相互独立：修改列表不会改变已生成的队列，临时调整队列也不会自动改写列表。需要保留临时顺序时，请保存队列。

关闭窗口后音乐继续播放，点击 Dock 图标可重新打开。退出应用后，再次打开会恢复队列、音量和播放位置，默认暂停。

## 水族箱

在「正在播放」页的播放面板顶部切换「频谱／水族箱」，歌曲、播放队列和进度保持连续。暂停音乐后鱼群继续缓慢游动，切歌不会重置场景。

点击「沉浸全屏」图标，让水族箱铺满屏幕。移动鼠标或操作键盘会显示播放控制，闲置 3 秒后隐藏；鼠标停在控件上时保持显示。按 Esc 或点击「退出全屏」返回，进入前已处于窗口全屏时会保留原全屏状态。空格播放／暂停，上下键调整音量，左右键切换曲目。

鱼缸面板的画面切换按钮旁和沉浸全屏控制区都有「气泡音」快捷开关，立即保存并与场景配置同步；音乐音量和气泡环境音音量各自独立。

点击鱼缸面板右上角的调节按钮打开场景配置：

- 从 28 个鱼种中选择，每种 0～3 条，总数最多 40 条；默认 8 条。
- 海月水母默认 3 只，可调整为 0～5 只；透明伞体缓慢收缩，口腕与短触手随水流摆动。
- 单独开关洞穴海鳗、沙地海星、气泡和水波光纹。
- 选择蓝黑或纯蓝背板，以及标准／省电绘制质量。
- 独立开启气泡环境音并调整音量，可在音乐播放时自动降低环境音。

点击「应用」保存配置，下次打开自动恢复。离开水族箱、切换回频谱、隐藏或最小化窗口时，场景停止绘制、环境音暂停；回到页面后恢复。关闭主窗口不会停止原来的音乐播放。睡眠定时结束时，音乐和环境音都会停止。

## 睡眠定时

点击底部播放器的月亮图标，可选择 15、30、45、60 分钟，或「当前曲目结束」。再次打开可查看剩余时间、切换模式或关闭定时。

倒计时按自然时间推进：暂停、切歌和关闭主窗口都不会重置；系统休眠后如果已经到期，唤醒时保持暂停。退出应用会取消定时，重启后不恢复。

「当前曲目结束」会在音频自然结束后停止，优先于单曲或队列循环；手动切歌后会等待新曲目结束。定时完成保留当前音频和队列，只暂停播放器，不让电脑休眠或退出应用。

## 单曲收听统计

在音乐库右键点击一首音频，选择「查看收听统计」；也可以点击「播放统计」中的常听音频。

详情显示累计实际播放时长、完整播放次数、累计播放天数和最近一次有实际收听记录的会话开始时间。可切换最近 7 天、30 天或全部，点击或拖动图表查看每日数值，向下滚动查看历史会话并分批加载更多记录。

跨日会话在记录中保留整次实际时长，趋势图按实际收听日期分摊。不同播放列表里的同一音频共用统计，原始文件暂时不可用时仍可查看历史。

## 听力足迹

「播放统计」中的年度日历展示每天的收听量，支持切换年份及「播放时长／完整播放次数」。每列一周，星期一在最上方；窄窗口可横向滚动。

悬停日期可查看时长和次数，点击日期可查看当天听过的音频。相同音频当天的多次播放会合并展示，点击音频可继续查看单曲统计。空日期显示空记录，未来日期不能打开历史详情。

热力图获得键盘焦点后，上下键移动相邻日期，左右键移动一周，Return 打开日期详情。颜色仅表示实际收听量，不设置打卡目标或学习评分。

## 快捷键

| 按键 | 操作 |
|---|---|
| 空格 / `⌘P` | 播放或暂停 |
| `←` | 直接切换上一首 |
| `→` | 切换下一首 |
| `↑` / `↓` | 音量增加或减少 5% |
| `⌘O` | 添加音频目录 |
| `⌘R` | 切换播放模式 |
| `⌘,` | 打开设置 |
| `⌘Q` | 退出应用 |

裸方向键只在「正在播放」页、且输入框、列表、下拉选择器或滑块没有键盘焦点时控制播放器。其他页面保留原生方向键导航，`Shift + 方向键` 可用于扩展列表选择。长按上下键可连续调节音量，长按左右键不会连续切歌。

原有 `⌘←` / `⌘→` 切歌快捷键仍可使用；`⌘←` 在当前歌曲播放超过 3 秒时先回到开头。

## 外观与播放统计

设置支持跟随系统、浅色和深色主题，以及冰川蓝、薄荷绿、薰衣草紫和暖珊瑚强调色。

「播放统计」显示实际播放时长、完整播放次数、最近 7 天的播放时长和常听音频。暂停、拖动跳过的部分和休眠不计入播放时长；歌曲自然结束且实际覆盖至少 90% 内容时计为完整播放。

## 本地数据与目录访问

音乐库索引、播放列表和播放记录保存在：

```text
~/Library/Application Support/LittleEars/
```

需要备份时，先退出应用，再备份该目录。原始音频需要单独备份。

目录内容变化后，可以刷新音乐库。若目录无法访问，可右键点击左侧目录，选择「重新授权目录…」。文件丢失后，应用会保留已有记录和统计；恢复文件后可刷新目录检查。
