# Little Ears

Little Ears 是一款 macOS 原生本地音频播放器，适合英语熏听、故事播放和日常听音乐。音频保留在原来的文件夹中，应用完全离线运行。

支持 MP3、M4A、WAV、AIFF、CAF 和 FLAC，要求 macOS 14 或更新版本。

## 开始使用

1. 将 `Little Ears.app` 放入「应用程序」，打开应用。
2. 在「音乐库」点击「选择文件夹」或「添加目录」，选择音频所在的文件夹。
3. 双击一首歌曲开始播放，或点击「播放」按当前列表顺序播放。

添加目录只会建立索引，不会复制、移动或修改原始音频。点击左侧目录可浏览其中的歌曲；勾选「子目录」可同时查看下级文件夹中的音频。音乐库支持搜索，以及按名称或时长排序。

拖动侧栏右缘可调整宽度，悬停在较长的目录或列表名称上可查看完整名称。

## 选择多首歌曲

- 单击选中一首歌曲。
- 按住 `⌘` 点击，添加或取消不连续的选择。
- 先选一首，再按住 `Shift` 点击另一首，选中连续范围。
- 点击列表底部的「全选」或「取消选择」，批量调整选择。

音乐库选中歌曲后，点击「加入播放列表」，选择已有列表或新建列表。可以从不同目录分批加入歌曲；点击「播放所选」可只播放选中的歌曲。

## 管理播放列表

播放列表用于保存挑选的歌曲及其播放顺序，同一首歌曲可以加入多次。

- **新建**：点击左侧「播放列表」旁的 `+`，或从音乐库选择歌曲后新建列表。
- **重命名／删除**：右键点击左侧的具体列表名称，或使用列表页右上角的「…」菜单。
- **调整列表顺序**：拖动左侧列表名称，顺序自动保存。
- **调整歌曲顺序**：拖动歌曲左侧的排序手柄，顺序自动保存。
- **移除歌曲**：多选后点击「移除所选」，或在歌曲列表获得焦点时按 `Delete`。
- **播放**：打开列表后点击「播放」，或双击某首歌曲从该处开始。

删除列表或移除歌曲只影响播放列表，原始音频、播放记录和当前播放队列都会保留。

## 播放与队列

「正在播放」显示当前曲目、播放进度、实时音频频谱和播放队列。底部播放器提供暂停、切歌、音量及播放模式控制，支持顺序播放、队列循环和单曲循环。

播放页的进度条位于频谱面板内；其他页面可通过底部进度条调整播放位置。实时频谱随实际音频变化，暂停时保留画面，也可以在设置中关闭。

右侧队列支持双击跳转和拖拽排序。点击「保存队列」可另存为新播放列表，或确认后覆盖已有列表。

播放列表与当前队列相互独立：修改列表不会改变已生成的队列，临时调整队列也不会自动改写列表。需要保留临时顺序时，请保存队列。

关闭窗口后音乐继续播放，点击 Dock 图标可重新打开。退出应用后，再次打开会恢复队列、音量和播放位置，默认暂停。

## 快捷键

| 按键 | 操作 |
|---|---|
| 空格 / `⌘P` | 播放或暂停 |
| `←` | 直接切换上一首 |
| `→` | 切换下一首 |
| `↑` / `↓` | 音量增加或减少 5% |
| `⌘O` | 添加音频目录 |
| `⌘R` | 切换播放模式 |
| `⌘,` | 打开设置 |
| `⌘Q` | 退出应用 |

方向键在歌曲列表获得焦点时也能控制播放器。输入框、弹窗、下拉选择器和滑块保留原生键盘操作；`Shift + 方向键` 可用于扩展列表选择。长按上下键可连续调节音量，长按左右键不会连续切歌。

原有 `⌘←` / `⌘→` 切歌快捷键仍可使用；`⌘←` 在当前歌曲播放超过 3 秒时先回到开头。

## 外观与播放统计

设置支持跟随系统、浅色和深色主题，以及冰川蓝、薄荷绿、薰衣草紫和暖珊瑚强调色。

「播放统计」显示实际播放时长、完整播放次数、最近 7 天的播放时长和常听音频。暂停、拖动跳过的部分和休眠不计入播放时长；歌曲自然结束且实际覆盖至少 90% 内容时计为完整播放。

## 本地数据与目录访问

音乐库索引、播放列表和播放记录保存在：

```text
~/Library/Application Support/LittleEars/
```

需要备份时，先退出应用，再备份该目录。原始音频需要单独备份。

目录内容变化后，可以刷新音乐库。若目录无法访问，可右键点击左侧目录，选择「重新授权目录…」。文件丢失后，应用会保留已有记录和统计；恢复文件后可刷新目录检查。
